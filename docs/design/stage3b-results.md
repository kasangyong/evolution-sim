- 작성일: 2026-10-19
- 관련 설계: [stage3b-arch.md](stage3b-arch.md), [stage3a-results.md](stage3a-results.md)
- 측정 환경: RTX 2070 SUPER, GPU 경합 없음(게이트 중 다른 GPU 작업 없음).
- 평가: 2차에 **통과** (§6).
- 진행 방식: 단계 3a 평가가 진행되는 동안 별도 작업 공간에서 구현했다. 3a가 통과한 뒤 3a의 최종 수정(세포 수 비례 추첨, 저서 부착)을 반영해 본 저장소로 옮겼다.

## 1. 구현 범위

| 항목 | 구현 |
|---|---|
| 유전체 | 17 → **124**. 형질 3개(포식 η, 최고 헤엄 속도, 먹이 크기 비율 문턱)와 뇌 가중치 104개를 뒤에 덧붙였다(결정 4 B안). 창시자 뇌 = 0 |
| 칸 집계 (`census`) | 칸마다 세포 수, 바이오매스, 만남 후보 슬롯 1개. 후보는 세포 수에 비례한 가중 표본추출(키 = 양자화한 −ln u / ncell + 슬롯 번호, `atomic_min`)로 고른다. 정렬 없음(결정 1 B안, 1차 평가 후 수정) |
| 뇌 (`think`) | 8 → 8 → 4, tanh. 입력: 빛, R·O 포화, 온도 편차, log(1 + 칸 세포 수), log(내 세포 크기 / 칸 평균), 에너지 비율, 바닥까지 거리. 출력: 이동 x, 이동 y, 사냥, 분열 억제 |
| 능동 이동 | 속도 = 최고 속도 유전자 × (출력 x, y). 비용 `k_move × 속도² × 몸`. 수동 표류는 그대로이고, 바닥 위 물 칸(저서 부착)에서는 수동 표류만 멈추고 헤엄은 된다 |
| 포식 (`predate`) | 한 입 = `k_pred × η_pred × 몸`을 먹이 몸에서 원자적으로 뺀다. 동화 효율 0.6만큼 포식자 몸, 나머지는 사체. 먹이 세포 크기 × 문턱 < 포식자 세포 크기여야 한다. 먹이 묶음 n은 같은 비율로 준다 |
| 한 tick 순서 | `move → census → think → predate → metabolize → die → weigh_divisions → reproduce` |

### 구현 중 바꾼 것 (설계 대비)

| 변경 | 이유 (측정) |
|---|---|
| 사냥·분열 억제는 출력 > **0.5**일 때만 켠다 | 문턱 0이면 첫 돌연변이로 생긴 작은 가중치가 자손의 약 절반에서 분열 억제를 켰다. CUDA 검사에서 개체 수가 2.6만(3a) → 6,500(3b)으로 떨어졌다. 0.5로 바꾼 뒤 회복했다 |
| 큰 돌연변이(1%)는 형질 유전자에만 | 유전자가 124개라 균일 추첨이면 대사 유전자에 걸릴 확률이 약 1/7로 준다. 광합성 등 0에서 시작하는 유전자의 탈출 경로를 보존한다. 뇌는 가우시안 돌연변이로 진화한다 |
| 성장 상한(분열 크기 2배)에 닿은 세포는 먹지 않는다 | 포식 이득이 탄소고정 상한을 우회해 세포가 상한을 넘었다(슈퍼개체 테스트 실패) |
| 다 먹힌 먹이는 포식 커널에서 바로 사망 처리 | **NaN 버그.** 몸이 정확히 0인 산 세포가 대사에서 빛 몫 0/0을 만들었다. NaN 비교는 거짓이라 사망 판정도 피했고, NaN이 화학장으로 퍼져 9천 tick에 전멸했다. 뇌 입력과 빛 몫에도 0 나눗셈 방지를 넣었다 |

- **능동 이동이 진화**했고(속도 0 → 0.42), 빛 받는 개체가 1.6만~1.9만으로 늘었다. 3a에서는 얕은 열수구에서만 드물게 열리던 광합성 경로가 이동으로 열린 것으로 **추정**한다.
- **포식이 퍼졌다.** 81%가 포식 η > 0.1이고 약 70%가 사냥 중이다. 포식이 너무 쉬운지는 장기 관찰이 필요하다(§5).

## 5. 남은 위험

- 포식이 매우 흔하다. 먹이 크기 문턱(기본 2배)과 한 입 크기가 결과를 좌우할 수 있다.
- 칸당 만남 후보가 tick마다 1개다. 붐비는 칸에서는 포식자들이 같은 먹이를 노린다.
- 만남 후보로 포식자 자신이 뽑히면(세포 수에 비례) 그 tick은 물지 못한다. 큰 묶음 포식자는 먹이가 적은 칸에서 성공률이 낮다. 같은 클론끼리 먹지 않는 것으로 본다(2차 평가 n1).
- 포식의 기능 반응이 사실상 포화형이다. 칸에 먹이가 하나만 있어도 매 tick 만난다(1차 평가 m3, 사용자 확인 항목).
- 게이트 v2의 10만 tick 슬롯 수(약 1.9천~7천)가 v1(약 2.8천~1.3만)보다 낮다. 세포 수 비례 만남으로 포식 압력이 커진 효과로 **추정**한다(2차 평가 n2).
- 슈퍼개체 n의 감소는 원자 연산이 아니다(개수일 뿐 수지와 무관). 여러 포식자가 동시에 물면 약간 부정확하다.
- 3a에서 이월: 영구 눈덩이 지구(사용자 결정 필요), 너무 빠른 출현.
