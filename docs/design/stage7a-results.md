## 1. 구현

| 항목 | 구현 |
|---|---|
| 감각 | 수소, 황화물, 산소, 빛 4가지를 "적응된 수준"(개체마다 기억하는 로그 평균)과 비교한 log(지금/기억)을 뇌 입력 8~11로 준다. 기억은 적응 시간 상수 유전자(1~20 tick)에 따라 지금 값으로 따라간다. 창시 세포는 태어난 곳에 적응된 상태로 시작한다 |
| 운동 | 직진과 방향 바꾸기. 개체가 진행 방향을 기억하고, 뇌 출력 0이 0.5를 넘으면 무작위 새 방향, 출력 1이 속도(0 ~ 최고 속도)다. 비용은 그대로 `k_move × 속도² × 몸` |
| 뇌 | 12 → 8 → 4, 가중치 136개. 유지비 `k_brain(3e-5) × Σ|가중치| × 몸`. 뇌 계산은 매 tick 한 번 |
| 유전체 | 158개(형질 20 + 뇌 136 + 부착 + 적응 시간). 스냅샷 스키마 3 |
| 사건 기록 | `evo/analysis/events.py`. 2,000 tick마다 요약을 보고 광합성 번성, 산소 증가, 메탄 붕괴, 결빙·해빙, 대멸종, 새 주요 종 출현·멸종, 새 능력(포식·군체·헤엄·화학 감각) 확산을 감지한다. 사건마다 바다 전체 화면, 장소가 있으면 확대 화면을 `events/`에 저장하고 `events.jsonl`에 설명과 숫자를 남긴다. 뷰어의 "사건 기록" 칸에서 보고 "그때로 가기"로 되감는다 |

## 4. 사건 기록 1차 실행에서 고친 것

첫 실시간 실행(81만 tick, 사건 81개)에서 사건 대부분이 잡음이었다.

| 문제 | 원인 | 수정 |
|---|---|---|
| "새 주요 종" 뒤 2,000 tick 만에 "멸종"이 수십 번 반복 | 종 판별이 매번 무작위 리더로 군집을 새로 나눠 ID가 흔들렸다 | 이전 종 중심을 먼저 리더로 쓴다(구성원 없는 리더는 버림). 감지기는 두 번 연속 주요해야 "출현", 알린 종이 두 번 연속 없어야 "사라짐"으로 기록한다 |
| tick 2,000에 "화학 감각 100%" | 돌연변이 표류만으로 감각 가중치 합이 문턱을 넘었다 | 감각 → 방향 바꾸기의 선형 민감도(Σ W2·W1)가 2를 넘고 헤엄치는 세포만 센다 |
| tick 2,000에 "포식 44%" | 포식 효율 유전자가 표류로 0.1을 넘었다 | 포식 효율 > 0.2이면서 지금 사냥 출력이 켜진 세포만 센다 |
