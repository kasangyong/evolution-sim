## 결정 1. 월드 표현 방식

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. 셀룰러 오토마타만 | 격자 칸 하나 = 생물 하나 | 단순하고 GPU 친화적이다. 하지만 뇌·이동·몸 크기 표현이 어렵다 |
| B. 연속 장(Lenia류) | 생물이 연속장의 패턴으로 나타난다 | 유전체·종 개념이 모호해서 계통수·검사가 거의 불가능하다 |
| **C. 하이브리드: 환경은 격자, 생물은 입자** | 화학·온도·빛은 격자장, 생물은 위치·유전체를 가진 에이전트 | 구현량은 중간이다. 유전체·검사·계통이 자연스럽다 |

**추천: C.**
- 월드는 2D 바다 단면이고 기본 1024(가로) × 384(깊이) 칸이다.
- 지형은 시드로 생성한다.
  - 대륙붕: 얕아서 해저까지 빛이 닿는다.
  - 심해 분지.
  - 열수구 3~6개.

**예상 리스크**
- 같은 칸에 개체가 몰리면 원자 연산 경합으로 느려진다.
  - 완화: 칸당 섭취량에 상한을 둔다.

### 2.1 장 (격자 칸마다)

| 장 | 의미 |
|---|---|
| `H` | 고에너지 환원제 (H₂). **열수구에서만 공급**. 초기 생명의 에너지원 |
| `R` | 저에너지 환원성 물질 (H₂S/Fe²⁺ 묶음). 전자 공여체 |
| `X` | 산화된 물질 (SO₄²⁻/Fe³⁺ 묶음). R의 산화 산물이자 무산소 호흡의 전자 수용체 |
| `C` | 용존 무기 탄소 (CO₂) |
| `O` | 용존 산소 (O₂) |
| `M` | 메탄 (CH₄). 무산소 분해·메탄 생성의 산물이자 온실가스 |
| `N` | 영양염 (N/P 묶음) |
| `D` | 유기 잔해 (사체). 탄소와 질소를 C:N = 6.6 고정비로 보유 |
| `L`, `T` | 빛, 온도. 저장하지 않고 매 tick 계산한다 |

### 2.2 원소 보존과 원천·싱크

- 추적 원소는 C, N, 그리고 산화환원 당량(전자) 세 가지다.
- 생물의 몸은 탄소 + 질소(C:N 고정)로 이루어진 물질이다.
- **에너지(ATP 성격의 스칼라)는 아래 반응으로만 생긴다.** 공짜 에너지는 없다.

| 원천 (맨틀 → 시스템) | 싱크 (시스템 → 지각) |
|---|---|
| 열수구: H, R, C, N, 열 | **유기물 매몰**: 해저 칸 D의 일정 비율이 매 tick `B_org`로 이동 |
| 화산(지질 시계, 포아송): 대기 CO₂, R | **대기 메탄 광분해 + 수소 우주 탈출**: 대기 M → C, 전자 8e가 우주로 손실(실제 시생대 지구의 산화 경로). 속도 ∝ 대기 M |
| | **풍화**: 대기 CO₂ → `B_carb`. 속도 ∝ exp(k·(T_s − T₀)) × (1 − 결빙률) |
| | **N 손실**: 매몰되는 D에 포함된 N + 무산소 칸의 1차 손실 `k_den·N` (탈질 근사, 산화환원 중립으로 단순화) |

`B_org`, `B_carb`는 전역 누적값이다(관찰·수지 검증용, 재순환 없음).

### 2.3 반응 화학량 표 (계수 확정, 전자 균형 검증됨)

물질마다 **전자 단위(e)**와 **화학 퍼텐셜(μ)**을 고정한다. 기준은 산화형(C, X, O) = 0이다.

| 물질 | e | μ (에너지 단위/물질 1단위) | μ/e |
|---|---|---|---|
| H (H₂) | +2 | 2.6 | 1.3 (가장 고에너지) |
| M (CH₄) | +8 | 7.2 | 0.9 |
| 몸C, D (CH₂O) | +4 | 4.0 | 1.0 |
| R | +2 | 1.4 | 0.7 |
| C, X | 0 | 0 | — |
| O (O₂) | −4 | 0 | — |
| N | 0 | 0 (산화환원 중립으로 단순화) | — |

**에너지 규칙 (영구기관 방지)**
- 모든 반응의 `ΔG = Σμ(산출) − Σμ(입력)`이다.
- 생물이 반응을 수행하면 다음과 같이 처리한다.
  - ΔG < 0이면 에너지 `−ΔG × η`를 얻는다(η < 1, 효소 유전자 효율).
  - ΔG > 0이면 에너지 `ΔG / η`를 지불해야 한다.
- 정반응과 역반응은 ΔG 부호가 반대다. 게다가 η < 1이므로 **어떤 반응 사이클도 순에너지를 만들지 못한다.**
- 외부 에너지는 단 두 가지다.
  - 빛(광합성의 ΔG 지불)
  - 열수구·화산이 공급하는 환원제(H, R)의 μ

| 반응 | 주체 | 화학량 | e (좌 → 우) | ΔG | 비고 |
|---|---|---|---|---|---|
| 수소 화학합성 | 생물 | 2H + C → 몸C | 4 → 4 | **−1.2** | 초기 세포의 생존 방식(LUCA 가설과 같은 계열) |
| 황 탄소고정 | 생물 | 2R + C → 몸C + 2X | 4 → 4 | +1.2 (지불) | 에너지는 아래 황 산화로 충당 |
| 황 산화 | 생물 | 2R + O → 2X | 4 → 4 | −2.8 | O₂가 있어야 가능 → 산소 증가 후 열리는 생태 지위 |
| 광합성 | 생물 | C (+빛) → 몸C + O | 0 → 0 | +4.0 (빛으로 지불) | 빛 L에 비례, 상한 있음 |
| 호기 호흡 | 생물 | 몸C + O → C | 0 → 0 | **−4.0** | 수율 최고 |
| 무산소 호흡 | 생물 | 몸C + 2X → C + 2R | 4 → 4 | −1.2 | 황 탄소고정의 역반응. 한 바퀴 순에너지 = 1.2η − 1.2/η < 0 |
| 메탄 생성 | 생물 | 2몸C → C + M | 8 → 8 | −0.8 | 산화제 없이 가능한 유일한 호흡. 수율 최저 |
| 메탄 산화 | 생물 | M + 2O → C | 0 → 0 | −7.2 | O₂ 필요 |
| 성장 | 생물 | 몸C 증가분 × (1/6.6)만큼 N 섭취 | 중립 | 고정 비용 | |
| 포식 | 생물 | 피식자 몸C·N 일부 → 포식자, 나머지 → D | 중립 | 0 | 동화 효율 < 1 |
| 사망 | 생물 | 몸C, N → D | 중립 | 0 | |
| 호기 분해 | 장 | D + O → C (+N) | 0 → 0 | −4.0 (열로 소실) | |
| 무산소 분해 (X) | 장 | D + 2X → C + 2R (+N) | 4 → 4 | −1.2 (소실) | |
| 무산소 분해 (메탄) | 장 | 2D → C + M (+N) | 8 → 8 | −0.8 (소실) | 산화제가 없을 때의 기본 분해 경로(느림). **무산소 시대에도 C·N이 재순환**된다 |
| 비생물 산화 | 장 | 2R + O → 2X, 2H + O → ∅ (H₂O), M + 2O → C | 0 → 0 | 음수 (소실) | |
| 매몰 (싱크) | 장 | D → B_org | 시스템에서 +4 제거 | — | |

- rev 4의 발효는 메탄 생성으로 대체했다. 산화제가 없어도 메탄 생성으로 아주 적은 에너지를 얻을 수 있다.
- 유지 비용은 저장 에너지에서 차감한다. 저장 에너지가 부족하면 호흡으로 몸C를 태운다. 그것도 불가능하면 사망한다.
- **전역 산화환원 수지**는 `E = 4·(Σ몸C + ΣD) + 2·(ΣH + ΣR) + 8·(ΣM + 대기 M) − 4·(ΣO + 대기 O₂)`로 정의한다.
  - `E(t) = E(0) + Σ원천e − Σ싱크e`가 성립해야 한다.
- `ledger.py` 단위 테스트로 다음 세 가지를 검사한다.
  1. 반응마다 C·N·e 수지가 0인지.
  2. 반응마다 ΔG가 μ 표에서 계산되는지(하드코딩 금지).
  3. 정반응과 역반응을 연달아 수행했을 때 생물의 순에너지가 < 0인지.

### 2.4 산소가 각본 없이 쌓이는 메커니즘

- 광합성으로 만든 O₂는 같은 탄소가 호흡·분해되면 그대로 소비된다. 그래서 장기 순수지는 0이다.
- **순수 O₂ 축적 = 유기물 매몰로 빠져나간 탄소만큼의 O₂.** 이것은 실제 지구와 같은 원리다.
  - 전자 단위로 보면, 매몰 1단위가 +4e를 제거하므로 시스템에 −4e, 즉 O₂ 1단위가 남는다.
- 축적 조건(전자 단위)은 `4·F_매몰 + 8·F_메탄탈출 > 2·(F_H + F_R)`이다. 이것은 **필요조건**이다.
  - 이 조건이 지속되어 시스템 안의 환원제 재고(H, R, M)가 먼저 소진돼야 O₂가 남기 시작한다. 그 소진 기간이 곧 산소 증가 지연이다.
  - `F_H + F_R`은 열수구와 화산이 공급하는 환원제 플럭스다.
  - 무산소 분해 등 시스템 안의 산화환원 교환은 E를 보존하므로 이 부등식에 들어가지 않는다.
- 이 조건은 광합성 생물이 충분히 번성해야만 성립하고, 성립 시점은 그 세계의 진화에 달려 있다.
- 산소의 영향은 유전자에 따라 달라진다.
  - `산소 내성` 유전자가 낮으면 산소로부터 손상을 받는다.
  - 호기 호흡 유전자가 있으면 에너지 수율이 커진다.
  - 결과로 대멸종과 호기성 생물의 번성이 일어날 수 있다.

### 2.5 대기·기후 박스 (전역 1-박스)

1. 대기 CO₂·O₂·CH₄가 수면 칸과 기체를 교환한다. 단, **결빙된 칸은 교환을 차단**한다.
   - 대기 안에서 `k·M·O₂` 속도로 M + 2O → C가 일어난다. 이 항 때문에 산소 증가 → 메탄 온실 붕괴 → 냉각이라는 연쇄가 각본 없이 창발할 수 있다.
2. 수면 온도 `T_s = T₀ + a·ln(max(CO₂, CO₂_min)/CO₂₀) + a_M·√(대기 M) + b·(S − S₀)/S₀ − c·결빙률`. 결빙률이 곧 알베도 효과다.
   - CO₂ 하한 `CO₂_min`으로 ln 발산을 막는다.
   - 이완 시간을 두고 갱신해서 수치 진동을 막는다.
   - c/w 조합에 따라 쌍안정(눈덩이 지구 고착)이 생긴다. 단계 1에서 c/w와 a_M(√M 단위 포함)의 허용 범위를 문서화한다.
   - 히스테리시스 테스트: 테스트 전용 CO₂ 강제로 결빙 → 해빙이 가역적인지 확인한다.
3. 결빙률 = clamp((T_freeze − T_s) / w, 0, 1). 결빙된 수면은 빛을 차단한다.
4. 두 피드백이 서로를 상쇄한다.
   - 양의 피드백: 냉각 → 결빙 → 알베도 증가 → 더 냉각. 빙하기가 스스로 강화된다.
   - 음의 피드백: 결빙 → 풍화 정지 → 화산 CO₂ 누적 → 온난화 → 해빙. 빙하기에서 탈출하는 경로다.
   - 둘 다 규칙에서 창발하며, 사건 일정은 없다.

### 2.6 수송

- 확산: 모든 용존 장에 적용한다. 표층 혼합층(상위 ~10%)에서는 확산 계수를 크게 둔다.
- 이류: 고정된 대순환 유선 함수 1개로 계산한다. 연안 용승과 심층 복귀 흐름이 생긴다.
  - 영양염이 표층으로 돌아오는 경로다.
  - 이동 능력 0인 초기 세포가 표층에 닿을 수 있는 경로이기도 하다.
- 침강: D는 고정 침강 속도로 가라앉는다.
- 생물의 수동 운동: 국소 유속 + 랜덤 워크로 표류한다. 이동 유전자가 있으면 능동 이동이 추가된다.

### 2.7 초기 상태 (시생대 근사)

- 대기: 고 CO₂, O₂ = 0.
- 바다: 열수구 주변 H 풍부, R 풍부, X는 R의 5%(초기 재고 명시), M = 0, O = 0.
- 생물: 열수구 주변에 수소 화학합성 세포 200마리(결정 3 참조).

**예상 리스크**
- 계수가 많아서 균형 튜닝에 시간이 든다.
  - 완화: 모든 계수를 `config.py`의 dataclass 하나에 모은다.
  - S6 수지 검사를 자동 테스트로 둔다.
  - S4 10만 tick 게이트로 빠르게 반복한다.
  - 프리셋은 3개(안정/기본/가혹)를 둔다.
- 산소 축적이 끝내 일어나지 않는 세계도 정상 결과다. 다만 기본 프리셋에서 **가능은 해야** 한다.
  - 검증: 단계 3에서 "광합성 개체군을 인위로 심은 테스트 시나리오"로 메커니즘만 확인한다. 테스트 전용이며 실제 실행에는 쓰지 않는다.

## 결정 3. 유전체 → 형질 인코딩

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. 프로그램형 유전체 (Avida/Tierra식) | 유전체가 실행되는 명령어 | 표현력이 최고다. GPU 분기가 폭발하고 해석이 어렵다 |
| **B. 고정 길이 실수 벡터 = 형질 유전자 + 소형 신경망** | | GPU 친화적이고 검사 UI가 쉽다. 능력의 종류는 형질 목록으로 제한된다 |
| C. NEAT식 가변 토폴로지 뇌 | | GPU 구현이 복잡하다. 이후 확장 후보다 |

**추천: B.** 유전체는 `float32 × 128`이다.

| 구간 | 유전자 | 효과 |
|---|---|---|
| 형질 0–23 | 몸 크기, 분열 임계 에너지, 반응별 효소 효율 η(수소 화학합성·황 탄소고정·황 산화·광합성·호기 호흡·무산소 호흡·메탄 생성·메탄 산화), 포식 능력, 산소 내성, 온도 최적점·폭, 이동 속도, 감각 범위, 부착력, 체색 RGB, 돌연변이율 | 효율마다 **유지 비용**이 붙는다. 그래서 만능 생물이 불리하다 |
| 뇌 24–127 | 입력 8(빛, R, O, 온도, 주변 밀도, 주변 크기 차, 내 에너지, 바닥 거리) → 은닉 8 → 출력 4(이동 x, 이동 y, 섭취 모드, 분열 억제) | 행동이 진화한다 |

- 돌연변이: 분열 시 가우시안 노이즈를 더한다(σ = 돌연변이율 유전자). 낮은 확률로 유전자 하나를 큰 폭으로 바꾼다.
- 초기 세포
  - 수소 화학합성과 메탄 생성 효율만 중간이고, 나머지는 0 근처다.
  - 산소 내성 0, 이동 0, 뇌 0이다.
- 부착력이 높으면 분열 후 결합을 유지하고, 결합된 개체끼리 에너지를 공유한다. 군체가 창발할 수 있다.

**예상 리스크**
- 형질 목록에 없는 "새로운 능력"은 나오지 않는다. 이 방식의 본질적 한계다(Open question 4).

## 결정 4. GPU 개체 메모리 관리

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. Taichi 동적 SNode | 개체 수 가변 | 백엔드 지원이 제한적이고 느리다 |
| **B. 고정 용량 풀 + alive 플래그 + 원자 free-list (압축 없음)** | 최대 131,072 슬롯. 죽은 슬롯은 free-list에 반환하고 원자 pop으로 재사용한다 | 슬롯이 이동하지 않아 결합·포식 참조가 안전하다. 죽은 슬롯을 순회하는 비용은 alive 검사 하나로 미미하다 |
| C. 개체는 CPU, 장은 GPU | 개체 상태를 매 tick 파이썬/NumPy로 처리한다 | 5만 마리 이상에서 CPU↔GPU 전송과 파이썬 루프가 병목이 된다. S2 불가 |

**추천: B.**
- 메모리: 131,072 × (128 + ~24) × 4B ≈ **80MB**.
- 결합 참조는 `(slot, uid)` 쌍으로 한다. 슬롯의 uid가 다르면 끊어진 결합으로 처리한다.
- uid는 64비트이고 재사용하지 않는다. 부모 uid도 저장한다.
- free-list 경합 방지
  - **사망 반환(push)과 출생 할당(pop)을 별도 커널로 분리**한다. 같은 커널 안에서 push와 pop이 섞이지 않는다.
  - pop은 `old = ti.atomic_sub(top, 1)`로 한다. `old ≤ 0`이면 `atomic_add`로 되돌리고 번식을 실패 처리한다.
  - 경합 중 일부 번식이 추가로 실패할 수 있다. 허용한다.
- 공간 해시: 매 tick 카운팅 정렬로 재구성한다.
  - 칸별 개수는 원자 카운트로 센다.
  - prefix-sum은 `ti.algorithms.PrefixSumExecutor`(CUDA)로 한다.
  - 그다음 산포(scatter)한다.
- 수용력: 풀이 꽉 차면 번식이 실패한다. 이것은 자연스러운 상한이다.

**예상 리스크**
- GPU 원자 할당은 비결정적이다. 그래서 S1은 CPU 디버그 백엔드로 한정했다.
  - CPU 백엔드도 멀티스레드이므로, 디버그 모드에서는 `ti.init(arch=ti.cpu, cpu_max_num_threads=1)`로 실행한다.

## 결정 6. 관찰 UI, 렌더링, 실행 루프

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. Taichi GGUI만 | | 그래프·트리 위젯이 빈약하다. R6를 충족하기 어렵다 |
| **B. Taichi(계산) + Dear PyGui(창·ImPlot·위젯)** | 월드 이미지를 Taichi로 만들어 텍스처로 업로드한다 | 프레임당 ~1.5MB의 GPU→CPU 복사가 생긴다(무시 가능) |
| C. 시뮬 별도 프로세스 + 웹 대시보드 | | 구현량이 2배다 |

**추천: B.**
- **실행 루프는 단일 스레드**다. Taichi 커널을 여러 스레드에서 호출하지 않는다.
  - 매 렌더 프레임(목표 30fps)마다 "배속 × tick" 또는 시간 예산(최대 배속 시 ~28ms)만큼 tick을 돌린다.
  - 그다음 렌더하고 UI 이벤트를 처리한다.
  - 최대 배속에서는 렌더를 5fps로 낮춰 시뮬에 시간을 준다.
  - Taichi 커널 호출은 비동기다. 시간 예산을 판정하기 전에 `ti.sync()`를 호출해 실제 실행 시간을 잰다.
  - Dear PyGui의 vsync는 끈다.

**화면 구성**

| 영역 | 내용 |
|---|---|
| 중앙 | 월드 뷰. 생물은 체색이고, 배경 장은 선택형(빛/O/R/C/N/온도/결빙). 줌·팬 지원 |
| 우측 | 생물 검사기: 형질 막대, 뇌 가중치 히트맵, 에너지, 나이, 종 |
| 하단 | 그래프: 종별 개체수, 대기 O₂·CO₂, 수면 온도·결빙률, 에너지 전략 비율, B_org 누적 |
| 탭 | 계통수(종 분기 트리) |
| 상단 | 배속, 시계 2개, 세이브/로드, 사용 중인 GPU 이름 |

**종 판별**
- 매 2,000 tick마다 유전체 최대 1만 개를 CPU로 샘플링한다.
- 형질 유전자 거리로 리더-팔로워 군집을 만든다.
- 이전 종의 중심과 매칭되면 종 ID를 승계하고, 매칭되지 않으면 신종으로 판정하며 부모 종을 기록한다.

**예상 리스크**
- 종 임계값에 따라 결과가 크게 달라진다. 설정에서 조정할 수 있게 하고, 단계 4에서 기본값을 정한다.

## 결정 8. 실행 환경과 GPU 라이브러리

- 사실 확인
  - 시스템 Python은 3.14다.
  - taichi 최신 1.7.4는 Python 3.9–3.13 휠만 제공한다(PyPI 확인).

| 옵션 | trade-off |
|---|---|
| **A. `uv`로 프로젝트 전용 Python 3.12 venv + Taichi 1.7.4 (CUDA 백엔드 전용)** | 시스템을 건드리지 않고 재현 가능하다. Taichi는 1.7.x 이후 개발이 사실상 정체 상태다 |
| B. NVIDIA Warp | 활발히 유지보수되고 CUDA 성능이 좋다. Taichi보다 문서와 예제가 적다 |
| C. CuPy + 커스텀 CUDA 커널 | 자유도가 최고다. 커널을 CUDA C로 써야 해서 구현 부담이 크다 |

**추천: A.**
- 백엔드는 **CUDA 전용**이다. Vulkan은 float atomic 등 확장 의존이 있어서 지원 대상에서 제외한다.
- 시작 시 GPU 이름을 로그와 UI에 표시하고, NVIDIA가 아니면 경고한다.

**예상 리스크**
- Taichi가 정체되어서 버그를 만나면 고쳐지지 않을 수 있다.
  - 완화: 커널을 `world/`·`life/` 모듈 안에 격리한다.
  - **단계 1 종료 시점을 결정 지점으로 둔다.** CUDA 동작, atomic, 성능 중 하나라도 실패하면 Warp(B)로 전환한다.

## Open questions (사용자 확인 필요)

1. **월드 크기**: 기본 1024 × 384 칸으로 가도 되는지.
2. **육지**: 이번 범위는 바다만이다. 육지 상륙은 이후 확장으로 미루는 데 동의하는지.
3. **시작 전 설정**: "개입 없음"은 시작 후 기준이다. 시작 전에 프리셋(안정/기본/가혹)과 시드를 고르는 것은 허용되는지.
4. **진화의 한계**: 능력의 종류는 형질 목록(약 24개)으로 한정되고, 그 조합과 행동이 자유롭게 진화한다. 이 수준이면 괜찮은지.
