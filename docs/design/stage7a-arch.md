# 단계 7a 설계 — 미생물의 화학 감각 (주화성)

- 작성일: 2026-10-20
- 관련 설계: [stage3b-arch.md](stage3b-arch.md)(지금의 뇌), [stage6-arch.md](stage6-arch.md)
- 사용자 요구(2026-10-20): "너무 단순하게 말고 실제처럼". 신경계가 진화한 실제 순서를 따른다. ① 미생물의 화학 감각 → (② 세포 분업 → ③ 신경 그물) → ④ 중추 뇌와 학습. 이번은 ①이고, 그다음 ④로 간다.
- 원칙: 뇌를 넣어 주지 않는다. 뇌를 가질 수 있는 규칙을 주고, 쓸지 말지는 진화가 정한다.

## 0. 실제 세균의 주화성 (모형의 근거)

- 세균은 몸이 작아서 몸 양 끝의 농도 차이를 잴 수 없다. 대신 **시간 비교**를 한다. 수용체가 지금 농도를 "적응된 수준"(몇 초에 걸친 평균, 메틸화로 구현됨)과 비교한다.
- 나아지면 직진(run)을 오래 하고, 나빠지면 방향을 무작위로 바꾼다(tumble). 이 단순한 규칙만으로 좋은 쪽으로 평균 이동한다(편향된 무작위 걸음).
- 감각과 운동 장치(편모)에는 에너지가 든다.

## 결정 1. 감각 입력

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. 공간 기울기(이웃 칸 차이) | 좌우·상하 칸의 농도 차이를 직접 본다 | 단순하지만 세균 크기에서는 비현실적이다 |
| **B. 시간 비교(적응)** | 물질 4종(H₂, 황화물, O₂, 빛)마다 개체가 "적응 수준"을 기억한다(지수 이동 평균, 시간 상수 τ 유전자). 입력 = log(지금 / 적응 수준) | 실제 세균과 같은 원리다. 개체마다 기억 4개(16 B)만 더 든다 |

**추천: B.** 기존 입력 8개에 시간 비교 4개를 더해 12개가 된다. 적응 시간 상수는 유전자로 둬서 진화하게 한다(1~20 tick).

## 결정 2. 운동 방식

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. 지금 방식 유지 | 뇌가 x·y 속도를 직접 낸다 | 세균은 원하는 방향을 직접 고를 수 없다. 비현실적이다 |
| **B. 직진과 방향 바꾸기(run-and-tumble)** | 개체가 진행 방향(각도)을 기억한다. 뇌 출력 하나가 방향 바꾸기(> 0.5면 무작위 새 방향), 하나가 속도(0~최고 속도)다 | 실제 세균의 운동이다. 방향을 직접 못 고르므로 감각을 잘 써야만 좋은 쪽으로 간다 |

**추천: B.** 출력 4개의 뜻을 바꾼다: [방향 바꾸기, 속도, 사냥, 분열 보류]. 사냥·분열 보류는 그대로다.

## 결정 3. 뇌의 비용

| 옵션 | 설명 | trade-off |
|---|---|---|
| A. 비용 없음 (지금) | | 쓸모없는 연결도 공짜라 크기가 표류한다 |
| **B. 연결 강도 합에 비례한 유지비** | `k_brain × Σ|가중치| × 몸` | 실제 신경·감각 단백질처럼 쓰는 만큼 든다. 도움이 안 되는 연결은 선택으로 줄어든다. 단계 3b 평가가 지적한 "뇌 가중치는 선택과 표류를 구분할 수 없음"도 이 비용으로 구분할 수 있게 된다 |

**추천: B.** `k_brain`은 연결 하나(가중치 1)당 기본 유지비의 1% 수준으로 시작해 측정으로 정한다.

## 결정 4. 유전체와 호환

- 뇌: 12 → 8 → 4. 가중치 8×12 + 편향 8 + 4×8 = 136개(지금 104). 적응 시간 상수 유전자 1개를 덧붙인다.
- 뇌 유전자 위치가 바뀌므로 스냅샷 스키마 3. 이전 저장점은 읽지 않는다.
- 창시자 뇌는 0이다. 감각을 쓰는 계통은 돌연변이로 생겨야 한다.

## 통과 기준

| 기준 | 내용 |
|---|---|
| 적응 | 단위 테스트: 농도가 일정하면 입력이 0으로 수렴하고, 오르면 양수, 내리면 음수 |
| 방향 바꾸기 | 단위 테스트: 출력이 문턱을 넘으면 방향이 무작위로 바뀌고, 아니면 유지된다 |
| 주화성 작동 | 손으로 정한 가중치(나빠지면 방향 바꾸기)로 정적인 기울기 속에서 개체군이 평균적으로 높은 쪽으로 이동한다. 같은 가중치를 0으로 하면 이동하지 않는다 |
| 뇌 비용 | 단위 테스트: Σ|가중치|에 비례한 에너지 차감 |
| 진화 관찰 | 게이트 실행에서 감각 가중치의 크기와 방향 바꾸기 반응이 표류(중립 유전자)와 다르게 움직이는지 기록 |
| S4·S6·S2 | 유지. 다시 잰다 |
