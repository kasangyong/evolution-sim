# 단계 7d 결과 — 살면서 배우기

- 설계: [stage7b-arch.md](stage7b-arch.md)의 "7d 준비"와 "7d 구현 결정"
- 측정 환경: RTX 2070 SUPER. 게이트 중 사용자 뷰어는 디스크 보호를 위해 일시정지(2,758만 tick).

## 1. 7d 준비 (7c 평가 2차 지적)

| 부분 | 내용 |
|---|---|
| 공유 뉴런 풀 | 뉴런 262,144개(시냅스 포함 약 55 MB)를 모든 생물체가 나눠 쓴다. 생물체는 뉴런 번호 목록만 든다. 발생(`wire`)이 pop, 몸이 바뀌거나 죽으면 `integrity`가 push |
| 생물체 표 | 8,192 → 65,536. S2는 그대로(232 tick/s) |
| 포화 기록 | 표가 가득 차서 실패한 전환, 풀이 가득 차서 못 자란 뉴런을 센다. 통계·게이트 로그·사건 기록("생물체 표 가득 참(계산 상한)") |
| 스키마 6 | 살아 있는 생물체 행과 그들이 쓰는 뉴런만 압축 저장. 되감아도 회로가 그대로 돌아온다(`test_a_nervous_system_survives_a_snapshot_round_trip`) |
| 확인 | 생활사 검사(신경 설계, 열수구 H₂ 8배): 생물체 약 200마리, 거절 0, 뉴런 약 5,500개 사용 |

## 2. 구현 (학습)

| 부분 | 내용 | 위치 |
|---|---|---|
| 유전자 | 32개 덧붙임(298 → 330). 유형마다 조절 뉴런 여부, 그 유형으로 들어오는 시냅스의 학습률 η(−0.1~0.1), 그 유형에서 나가는 시냅스의 습관화 u(0~0.5), 회복 시간 τ(1~200 tick). 창시자는 모두 0(학습 없음) | `genome.py` |
| 시냅스 | 유효 세기 = (발생 세기 w₀ + 배운 변화 Δ) × 자원 r | `neural` |
| 조절 신호 | 조절 뉴런들의 평균 출력에서 최근 평균(20 tick)을 뺀 **변화분** m을 몸 전체에 퍼뜨림. 도파민 뉴런이 수준이 아니라 뜻밖의 일에 터지듯이(Schultz 1997) | `learn` |
| 3요소 학습 | Δ += η × m × 앞 × 뒤 − λΔ, \|Δ\| ≤ 4, λ = 1e-3/tick(잊음) | `learn` |
| 습관화 | r += (1 − r)/τ − u × \|앞\| × r | `learn` |
| 비용 | 학습률 있는 시냅스마다 2e-8/tick | `config.py` |
| 물려주지 않음 | 새 뉴런은 Δ = 0, r = 1로 자란다. **덧붙이기 발생**: 마디가 늘면 그 마디의 뉴런만 더하고, 몸이 끊기면 떨어진 마디의 뉴런만 반납한다(남은 시냅스는 번호를 다시 매김). 나머지 뉴런과 배운 것은 그대로 | `wire`, `drop_neurons` |
| 저장 | 스키마 7: 뉴런 풀의 Δ, r까지 저장. 스키마 6은 Δ = 0, r = 1로 읽는다 | `snapshot.py` |
| 보기 | 뇌 보기: 선 굵기 = \|Δ\|, 조절 신호 값, 배워서 바뀐 시냅스 수 | `web.html` |
| 사건 | "살면서 배우기": 시냅스 \|Δ\| 평균이 0.1을 넘은 생물체가 생김 | `events.py` |

| 저장 | `test_what_was_learned_survives_a_snapshot` |

## 4. 구현 중 발견하고 고친 것

| 증상 | 원인 | 조치 |
|---|---|---|
| 전체 테스트가 51% 지점에서 비정상 종료(Windows access violation, 세계를 만드는 중) | 세계마다 커널을 따로 컴파일하고 런타임 전체에서 해제하지 않아 메모리가 쌓였다. 디스크가 거의 차서(여유 12 GB) 페이지 파일도 늘 수 없었다(추정) | 테스트마다 Taichi 런타임을 새로 연다(`conftest.py`). 메모리가 풀리고, 모든 테스트가 같은 난수 상태에서 시작한다(전체 묶음에서만 깨지던 종류의 문제가 사라진다). 시간도 55분 → 19분 |
| 디스크 여유 12 GB | 뷰어를 다시 켤 때마다 새 기록 폴더(예산 20 GB)가 생겼다. 기록 폴더 합계 약 100 GB | 뷰어 일시정지. 예전 폴더 삭제는 사용자 답을 기다린다 |

## 5. 평가 1차 지적과 조치

| 지적 | 조치 | 확인 |
|---|---|---|
| Major: 몸이 자랄 때마다 뇌 전체를 새로 만들어 배운 것이 지워짐 | 덧붙이기 발생(위 표). 생물체마다 "마지막 전체 재발생 이후 수명 비율"을 잰다(`since_wire`) | `test_a_growing_body_keeps_what_it_learned`, `test_a_cut_body_keeps_the_front_and_drops_the_rest`. 생활사 검사에서 비율 1.00(태어난 뒤 전체 재발생 없음) |
| 연합 학습 테스트의 대조군이 사실상 "벌"이고 감각 적응이 꺼져 있음 | 진짜 비대조군(냄새와 먹이를 같은 양, 25 tick 떨어뜨려 겪음)과 적응을 켠 조건(매 tick `think`) 추가 | 짝지음 Δ > 0.3, 비대조군은 그 10% 미만. 적응을 켜도 짝지음만 배운다 |
| 디스크 여유 확인 없음 | 기록 예산 = min(설정, 이미 쓴 양 + 여유 − 5 GB). 여유가 5 GB 미만이면 기록을 건너뛰고 수를 세어 화면에 알림 | `test_a_nearly_full_drive_stops_recording_and_says_so` |

### 같이 찾아 고친 것: 학습이 상한에 붙음

- 1차 게이트(`runs/s4_gate_7d.log`)에서 배운 변화 평균이 상한(4.0) 근처였다(3.77, 4.0). 생활사 검사에서도 생물체의 97%가 "배움" 문턱을 넘었다.
- 원인(계산): 조절 신호가 조절 뉴런 출력의 **수준**이었다. 조절 뉴런이 늘 켜져 있으면 함께 켜진 모든 시냅스가 평형 Δ = η·m·앞·뒤 / λ ≈ 10까지 자라 상한 4에서 잘린다. 연합 학습이 아니라 상시 활동에 의한 표류다.
- 조치: 조절 신호를 **변화분**(출력 − 최근 평균, 20 tick)으로 바꿨다. 변하지 않는 "보상"은 소식이 아니므로 첫 반응 뒤 잊는다. `test_a_constant_modulator_does_not_drive_synapses_to_their_bound`: 최고 0.3~4 사이, 2,500 tick 뒤 최고의 25% 미만.
- 1차 게이트 결과는 이 수정 전 코드다. 2차 게이트(`runs/s4_gate_7d2.log`)로 다시 잰다.
